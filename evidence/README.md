# Evidence Storage

This folder holds published evidence assets for the Hugo draft.

Rules:

- Keep original evidence files in `original/`.
- Put non-destructive display copies in `display/`.
- Put small preview images in `thumb/`.
- Do not overwrite originals.
- Record source, quality, transcription, and related pages in `data/evidence.yml`.

Recommended check path:

`checks/<source>/<yyyy-mm-dd>/<original|display|thumb>/<files>`
